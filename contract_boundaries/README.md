# 契约边界动作分叉实验

4种契约条件×3个描述版本，共12个计划会话。初次11个有效，另1个在工具完成后响应流断开；保留原始异常，按单独补跑协议同条件补跑1次，最终12个有效条件记录，共13次正式/补跑尝试。pilot另存，未计入结果。

阅读配套Word或研究设计与实验结果.md；analysis.json同时报告原始有效数、补跑次数、最终分组和脚本对照。results.json/CSV为原始12次，不覆盖异常；replacement_runs/e04保存额外补跑。不要只读原始CSV的boundary_correct列而忽略valid列。

任务是预构造的超时恢复交接微任务，后续工具动作由真实在线gpt-5.6-sol生成。通知只写本地模拟账本，不发送真实邮件。原请求不是模型本会话执行。所有条件支持请求级幂等，但键有效期、重试续做与旧响应回放、查询能否排除旧执行器后续写入不同。语义保证来自实验抽象，不完整复现供应商。

核心匹配对：过期键+终结查询需要查后补做，过期键+瞬时查询需要停止。两者查询内容都为第一项COMMITTED、第二项NOT_FOUND。服务预先固定合法不利调度，在不受保护的新提交前让旧请求完成剩余项；这是风险见证，不估计生产概率。

离线运行（标准库，Python 3.10+）：

```powershell
python run.py check
python analyze.py
```

analyze.py独立重算指标、核对冻结源码和模型/服务调用，保留原始及补跑统计。它导入本目录run.py执行确定性脚本对照，不访问网络。相邻live_experiment的两个依赖模块用于复用固定CLI命令构建，随包提供。

主指标为首次提交动作类正确并最终完成或必要未决；最终正确和安全分别报告。缓存重放后再正确补做可能最终正确但首次动作不经济，不应称为产生重复。本地评分对实际效果、公开回执、终结查询证据分别核对。参考策略full_rule利用契约真值，不是自然语言解析器，不计额外LLM会话。

在线重跑需自己的CLI登录及模型权限，修改相邻依赖experiment.py的BIN至自己的路径，在新目录运行；不要带入原protocol.json、runs或replacement_runs。先pilot再main。CLI原命令保存在command.json；模型精确后端快照和采样种子不可得。

限制：单模型；每描述版本仅一次；改写只含重排和有限同义词；初始已提交项总是第一项，未验证位置变化；无长文干扰、契约误报或跨工具迁移。不同条件不构成完整正交因素设计。12/12仅能排除列出的简单策略，不能证明人类意义的理解或排除更完整的条件规则。

包内公开事件排除reasoning类型，不含认证文件。原始失败会话缺少answer.txt是响应流中断的结果。
