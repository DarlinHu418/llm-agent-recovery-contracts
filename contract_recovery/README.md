# 契约感知恢复最小实验

18个正式在线模型会话：3种模拟契约×2种说明可见性×3种隐藏提交状态。CLI模型别名gpt-5.6-sol。无真实邮件。本实验从已经超时的恢复交接状态开始，原请求不是本会话模型执行的；后续恢复调用由真实模型生成。不是供应商接口的原生复现。

先读研究设计与实验结果.md或配套Word；results.csv逐会话；analysis.json汇总；protocol.json正式运行前本地冻结源码；runs/e01等为匿名会话目录，公开模型工具动作与服务状态可相互核验。raw reasoning事件不打包。

在本目录离线执行：

```powershell
python run.py check
python analyze.py
```

标准库即可。analyze.py独立重算关键指标，核对源代码哈希、模型与服务动作，运行四种脚本对照。确定性对照并非额外模型会话。依赖相邻live_experiment/experiment.py和notification_service.py，只复用原CLI命令构建；包中附有这两个固定文件。

主指标要求依可见信息作出安全决策，并在可恢复时取得回执完成，否则报告未决。三个隐藏世界初始观察一致；不能把随机差别归因于模型知道隐藏状态。说明不可见时无依据的写入即使碰巧没有重复，也不属于有依据的安全策略。相同效应的计数与决策风险分别报告。

在线独立复跑需自己的Codex CLI登录及模型权限。将源码复制到新目录，保留相邻live_experiment依赖，修改该依赖中BIN至自己的CLI路径并重新生成协议；不复制旧runs及protocol.json。先运行python run.py pilot，再python run.py main。已有run.json会复用，不覆盖正式结果。原协议的哈希仅用于核验原始数据。

单会话提示8次工具调用，服务10次后限制写工具，180秒进程上限，并发2。精确模型快照、采样种子不可得；仅每格一个会话，三种隐藏状态提供相同观察下三次采样，不做统计显著性推断。调试和连接pilot未混入正式18例。

该任务允许在逐项契约下拆批，但没有强制拆批。逐项与批次契约共享原批次重放安全策略，不能从成功率推出模型掌握了最佳划分策略。批次契约显式包含续做能力，不从“存在幂等键”推导该能力。不可见条件同时明确提示不能假定幂等，因此不能隔离纯粹的说明缺失效应，观察也可能主要反映指令遵循。

模型用量是CLI返回的累计tokens，缓存输入不等于收费金额。包不含登录文件或API密钥。正式源代码保持冻结，分析与文档脚本另行提供。
